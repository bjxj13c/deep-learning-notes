# 这是我学深度学习入门的练习文件夹

## 文件

| 文件 | 内容 | 测试集准确率 |
|---|---|---|
| `mnist_softmax.py` | MNIST 手写数字分类（`784 → 128 → ReLU → 10`） | **98.05%** |

## 实验一：隐藏层与激活函数

同一个任务、同一份数据、同样的训练流程和超参数
（`lr=0.1`、`batch_size=64`、`epochs=10`），**只改模型结构**：

| 模型 | 参数量 | 测试集准确率 |
|---|---|---|
| `Linear(784, 10)` | 7,850 | 92.20% |
| `Linear(784,128) → Linear(128,10)`（**无激活函数**） | 101,770 | 92.38% |
| `Linear(784,128) → ReLU → Linear(128,10)` | 101,770 | **97.49%** |

**结论**

- 第 2、3 行**参数量完全相同**，唯一区别是有无 ReLU，准确率相差 **5.11 个百分点**
- 没有激活函数时，多层线性网络等价于单层线性模型 ——
  第 2 行（92.38%）与单层（92.20%）几乎持平，印证了 `W₂(W₁x) = (W₂W₁)x`
- **起作用的是非线性，不是参数量**

## 实验二：训练轮数对过拟合的影响

模型不变（`784 → 128 → ReLU → 10`，101,770 参数），**只改训练轮数**：

| 轮数 | 训练集 | 测试集 | 训练-测试差距 |
|---|---|---|---|
| 10 | 98.32% | 97.49% | 0.83% |
| **30** | **99.84%** | **98.05%** | **1.79%** |

**多训练 20 轮：训练集涨了 1.52%，测试集只涨了 0.56% —— 收益差了近 3 倍。**

训练集的收益越来越难以转化为测试集的收益，这是**过拟合**的表现：
模型把多出来的容量用在"记住训练数据"上，而不是"学得更通用"。

> 测试集并未下降。因为 MNIST 任务较简单、模型容量有限，
> 这属于过拟合的**早期阶段** —— 差距扩大，但还没到测试集掉头的程度。
